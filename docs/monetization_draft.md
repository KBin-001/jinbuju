# jinbuju 商业化与变现路径方案（草案）

> 版本：v1.0 草案 · 日期：2026-07-20 · 作者：campaign-planner-2（战役策划师）
> 定位：纯商业策略与设计，**不涉及开发/代码**。支付/会员属产品重大功能，落地前须做影响评估（支付合规、数据模型、隐私），并由主理人/产品负责人拍板。
> 口径对齐：已交付的《0 预算自然流量获客方案》（北极星=12 周累计激活 ≥550；自然曝光 10万 / 注册 1000 / 激活率 45% / D1 35% / D7 18% / 小队率 50% / UGC 120；渠道全自然：公众号矩阵 / 视频号自然分发 / 搜一搜免费占位+小程序配置 / 小红书·社群 UGC / 老用户裂变）。
> 说明：本文沿用主理人口径称产品为 **jinbuju（微信小程序）**；其小程序注册展示名为「今日进度｜目标计划打卡」。

---

## 1. TL;DR

- **主推变现**：会员订阅（轻度、非付费墙），收入来自「固定期限一次性购买」（月/季/年卡），验证期**不上自动续费订阅**。
- **启动前提**：12 周 0 预算验证达标（激活 ≥550、D7 ≥15–18%、小队活跃率 ≥45–50%）且出现主动付费意向信号，才上线轻度会员 + 转化探针；**激活 <500、D7 <10% 严禁上付费**。
- **预期收入量级**：验证期 MRR 约 **¥250–880/月**（付费转化 3%–8% × 激活 550），远低于内容工时成本（约 ¥16k–36k/月），本质是「付费意愿验证 + AI 增量成本覆盖」，非全成本回收。
- **关键红线**：核心闭环（每日行动 / 目标进度 / 小队同行 / 基础 AI 提示）永远免费；虚拟商品必须走微信「小程序虚拟支付」合规类目；不接信息流广告、不卖用户数据、不做诱导分享 / 虚假促销 / 未明示自动续费。

## 3. 变现模式优先级矩阵

### 3.1 会员订阅（首选 · 契合度：高）
- **价值主张**：把免费版已验证的「真实数据 + AI 教练 + 小队同行」做得更深——AI 教练从「每日提示」升级为「周/月/年趋势复盘」，小队从「基础同行」升级为「更大房间 + 管理后台」，并解锁高级榜单、数据导出、连续行动勋章。
- **目标用户**：已建立稳定使用习惯、依赖 AI 复盘与小队机制的深度用户（即验证期主动表达「想要更深 AI 复盘」的那批人）。
- **定价思路**：月/季/年三档**固定期限一次性购买**；验证期不做自动续费（避开 DAU≥1万 门槛与 Apple 自动扣费复杂度，见第 6 节）。
- **与定位契合度**：**高**——增值不阻断核心闭环，强化「真实可信 / 安静有品质」。
- **风险**：过早变现伤留存；付费墙反噬；定价高于年轻用户心理阈值。应对见第 10 节。

### 3.2 小队 / 团队组织版（契合度：中高）
- **价值主张**：班级版、备考营、企业耐力挑战——更大房间（如 50–200 人）+ 管理后台（进度看板 / 教练托管 / 数据导出）。
- **目标用户**：班主任 / 备考机构 / 企业 HR / 社团组织者（轻量 B 小 b 或 B2B）。
- **定价思路**：按房间规模 / 时长席位费（如 ¥99–399/房间/周期），或机构年框。验证期暂不上，先做 1–2 个种子组织试点。
- **与定位契合度**：**中高**——天然延伸「小队同行」，但涉 B 端销售与合规，早期重。
- **风险**：B 端决策链长、合规（未成年人 / 教育机构资质）复杂。应对：验证期仅做种子试点，不做规模化销售。

### 3.3 内容 / 课程分成（契合度：中）
- **价值主张**：备考资料、习惯养成训练营，与 KOL / 机构分成（不改变核心产品，作为「精选内容」入口）。
- **目标用户**：有备考 / 技能提升明确需求的用户；KOL / 机构供给方。
- **定价思路**：分成制（平台抽成 15–30%），由供给方定价。
- **与定位契合度**：**中**——需谨慎选品，避免「课程商城」稀释「安静有品质」调性。
- **风险**：内容质量与调性失控、分成结算合规。应对：极早期不做，待品牌信任与审核机制成熟后小范围试。

### 3.4 品牌合作（谨慎 · 契合度：低）
- **价值主张**：仅接与调性一致的学习 / 生活品牌（如文具、专注类硬件、助学机构），且**明示「合作」**。
- **目标用户**：品牌广告主；用户侧为年轻学习 / 生活人群。
- **定价思路**：原生内容合作 / 小队冠名，非信息流硬广。
- **与定位契合度**：**低**——易伤质感，早期不做。
- **风险**：调性稀释、用户反感。应对：**明确「早期不做」**——在 DAU / 信任未起量前不接；何时可做：DAU≥1万 且用户调研显示对精选合作接受度高、且有严格「明示合作 + 调性审核」机制时，方以小批量原生合作试水。

### 3.5 明确不做
- **信息流广告**：伤质感 + 伤留存（与「安静有品质 / 真实可信」定位直接冲突，且会拉低 D7 / 小队率等核心指标）。
- **售卖用户数据**：违反隐私定位与法规（PIPL），摧毁「真实可信」信任基石，绝对不做。

## 4. 会员订阅详细设计

### 4.1 免费 vs 付费边界（永远免费）
- **今日 Tab**：每日行动创建 / 完成、基础打卡。
- **进度 Tab**：目标进度看板、基础趋势。
- **小队 Tab**：加入 / 创建基础小队（默认规模上限，如 ≤12 人）、同行互动。
- **AI 教练**：每日行动提示、基础复盘（文本）。
- **基础勋章 / 连续记录**。

### 4.2 付费解锁项清单（按价值分层）
- **L1 进阶 AI 复盘**：周 / 月 / 年趋势解读、关键节点回顾、横向对比分析（真实数据驱动，非虚拟成长物）。
- **L2 小队扩容**：更大或无限小队、自定义房间名 / 规则。
- **L3 数据特权**：高级榜单（非排行焦虑式，而是「同行进度可视化」）、数据导出（年度报告 PDF）、连续行动勋章体系。
- （组织版另计，验证期不上。）

### 4.3 定价梯度与测算依据
| 档位 | 参考区间 | 中值 | 月度等值 |
|------|---------|------|---------|
| 月卡 | ¥15–30 | ¥22 | ¥22/月 |
| 季卡 | ¥40–68 | ¥54 | ≈¥18/月 |
| 年卡 | ¥98–168 | ¥133 | ≈¥11/月 |

**依据**：
1. **目标用户付费力**：20 岁上下学生 / 年轻职场，月可支配收入有限，首单 <¥30 决策成本低。
2. **竞品参考**：习惯 / 自律 / 效率类 App 会员普遍落在 ¥12–30/月、年卡 ¥98–198 区间。
3. **微信内付费心理阈值**：小额首单易转化；年卡用「日均几毛钱」锚定，靠折扣驱动年卡占比。

**是否设 7 天试用 / 首年优惠**：验证期**不做「自动续费 7 天试用」**（易触发未明示自动续费合规风险 + 羊毛）；改设「首年 / 首季优惠」（如年卡首年 ¥98）与「付费功能预览但锁定」入口降低决策门槛；支持「3 天无理由退款」兜底信任。

### 4.4 上线原则
**轻度会员、非付费墙**。基础功能永远免费，付费为增值非阻断；不把任何核心闭环功能锁进付费墙。

## 5. ROI 测算（区间 + 假设）

### 5.1 基数与假设（对齐 0 预算方案）
- 12 周累计激活：**550**（达标基线）。
- 付费转化假设：**3%–8%**（验证期保守，因目标用户付费力有限 + 非付费墙）。
- 定价中值（固定期限一次性）：月 ¥22 / 季 ¥54 / 年 ¥133。
- 混合月度等值 ARPU 假设：年卡占比高（折扣驱动）→ 约 ¥13–15/月；若偏月卡 → ¥18–22/月。取区间 **¥13–20/月**。

### 5.2 测算表
| 指标 | 低（3% 转化） | 高（8% 转化） |
|------|--------------|--------------|
| 付费用户规模 | 550 × 3% ≈ **17 人** | 550 × 8% ≈ **44 人** |
| 月度等值 ARPU | ¥13 | ¥20 |
| **MRR（月度经常性收入）** | **≈¥221/月** | **≈¥880/月** |
| 内容工时成本（40–60 工时/周 × ¥80–150/工时） | 月 ≈¥13k–24k | 月 ≈¥24k–36k |
| 会员收入 vs 内容成本 | 远未覆盖 | 远未覆盖 |

> **结论**：验证期 MRR 约 **¥250–880/月**（取整区间），远低于内容工时成本（约 ¥16k–36k/月）。会员收入本质是「**付费意愿信号 + AI 增量推理成本覆盖**」（深度复盘调用大模型有边际成本，会员费应能覆盖该增量），**不是全成本回收**。

### 5.3 回本周期与敏感性
- **回本周期假设**：验证期不谈「回本」，谈「单付费用户贡献 vs 单用户 AI 服务成本」为正。放量后（DAU≥1万 + 自动续费订阅 + 小额付费获客）基数放大，MRR 按量级跃升，ROI 重构。
- **敏感性（转化率 ±1pp）**：付费用户 ±~4–5 人，MRR ±~¥60–100/月。
- **放量情景（供参考，非承诺）**：若激活达 5,000（小额付费获客后），5% 转化 = 250 付费 ×¥17 ≈ **¥4,250 MRR**；DAU≥1万 接入订阅后，年化空间显著放大。

> 标注：以上为**验证期小规模测算**，放量后（若进入小额付费获客）基数放大，ROI 重构。

## 6. 微信支付合规要点（必须写）

### 6.1 虚拟商品支付规则（微信官方强制）
- 小程序内虚拟商品（会员、解锁功能、订阅内容、付费功能、AI 服务等）的购买与支付**必须接入「小程序虚拟支付」**；不得使用普通微信支付，不得引导至 App / 公众号 / H5 / 个人号 / 网站收款（违规将封禁支付能力甚至下架）。
- jinbuju 属「**工具 / 社交**」类，属可开通虚拟支付类目（文娱、工具、社交、资讯、深度合成等）。

### 6.2 双端机制（以微信最新规则为准）
- **安卓 / 鸿蒙**：微信支付处理，按交易额收虚拟支付技术服务费（类目不同费率不同，工具 / 社交类通常有优惠，以开通时微信公示为准）。
- **iOS（2025-11 起微信已开放）**：会员订阅经微信虚拟支付 iOS 能力，底层由 **Apple 按周期自动扣费**，Apple 抽成约 **12%**（「小程序合作伙伴计划」），道具双端互通；要求微信客户端 ≥8.0.71、基础库 ≥3.16.1。

### 6.3 关键门槛（直接影响启动节奏）
- **自动续费订阅能力**要求：「已接入虚拟支付 + 首次发布 ≥90 天 + 完成认证备案 + **近 30 天日均 DAU ≥1万**」。
- → 验证期（550 激活、DAU 远低于 1万）**不具备自动续费订阅资格**，故验证期只做「**固定期限一次性购买**」（单次购买不需开通订阅能力）。DAU≥1万 后再接入自动续费。

### 6.4 建议路径与红线
- **建议路径**：会员走微信「小程序虚拟支付」合规类目；采用「**道具模式**」直接解锁功能，**避免「金币 / 虚拟币」等敏感代币设计**（既避微信风控，也契合「安静有品质」定位，不做养成系 / 可爱化货币）。
- **红线提示**：本方案只给策略；实际接入支付前**必须做影响评估**（支付接口、数据模型、隐私合规、微信平台规范），且需主理人 / 产品负责人拍板。
- **不做**：诱导分享、虚假促销、自动续费未明示等违规动作。

### 6.5 ⚠️ 跨文档风险提示（给主理人）
现有 `docs/payment-system-wechat-ios-dual-implementation-guide.md`（开发者「小程达」撰写，2026-07-16）与微信当前规则存在偏差：
1. 该文档主张 iOS 端由开发者**自建 Apple IAP**（30%/15% 抽成），与微信「虚拟支付」官方框架不一致——正确路径是走微信虚拟支付（iOS 底层由 Apple 扣 12%），开发者不应自建 IAP。
2. 未体现 **2025-11 iOS 虚拟支付开放**、**12% 苹果抽成**、**DAU≥1万 订阅门槛**、**道具模式 vs 代币模式**等最新规则。
3. 建议：启动任何支付开发前，由产品 / 开发按微信最新虚拟支付文档重写该指南，避免合规返工。

## 7. 启动门槛 KPI（明确「同时满足再启动」）

### 7.1 硬信号（必须满足）
- 12 周验证达标：激活累计 **≥550**、D7 稳定 **≥15–18%**、小队活跃率 **≥45–50%**。

### 7.2 软信号（建议满足）
- 用户主动表达「想要更深 AI 复盘 / 想导出年度报告 / 想要更大房间」（来自社群 / 反馈 / 设置页投票）。

### 7.3 启动动作
- 先上**轻度会员（非付费墙）** + 埋「转化意向」探针（设置页投票「想要高级 AI 复盘？」）；**不急着开发支付**。
- DAU 门槛提示：虚拟支付订阅能力需 DAU≥1万，验证期用「一次性购买」绕开，待起量再接自动续费。

### 7.4 禁止
- **激活 <500、D7 <10% 时上付费**（伤留存、违背 PMF 验证）。

## 8. 与 0 预算获客方案的衔接

### 8.1 阶段顺序
验证（0 预算获客）→ 商业化（本方案）；**顺序不能反**。

### 8.2 转化意向探针设计
- **设置页投票**：「想要高级 AI 复盘 / 年度报告 / 更大房间？」（多选）。
- **付费功能「预览但锁定」入口**：在 AI 教练 / 小队 / 导出页展示「Pro 预览」卡片，点击提示「会员即将开放，想先用？留下意向」。
- **社群 / 反馈信号收集**：在用户群与反馈入口设固定问题。

### 8.3 埋点建议
- 新增 `member_interest`（意向，含来源 / 选项）、`pay_convert`（付费转化，含档位 / 平台 / 金额）、`pay_refund`。
- 承接既有 `activate` / `team_join` 等事件，形成「激活 → 小队 → 意向 → 付费」漏斗。

### 8.4 与小额付费获客的协同
- 若验证达标后引入小额付费放大获客：本方案收入模型与之协同——小额付费获客放大注册 / 激活基数 → 付费用户规模与 MRR 同比例放大；同时自动续费订阅能力（DAU≥1万）随之解锁，LTV 提升。

## 9. 会员价值主张 messaging（给品牌审核用）

> 本节经 brand-analyst 终检：需轻量修改（勋章→年度印记【必修】、安静地比→安静地看见彼此的进度【建议】），改动已应用，应用后可发布 ✅。禁用词 23 条零命中；A5-N1~N6 除原 N5「比」边缘项已修正外全部通过。

### 9.1 一句话主张（守已锁定品牌调性）
「同行小队已经陪你走了很远；会员，让 AI 教练把这段路看得更清楚。」

### 9.2 三个支撑点
1. **AI 教练深度复盘**：把每周、每月、每年的真实数据，讲成你看得懂的进展——不是打分，是看清自己怎么一步步走完的。（用真实数据，避「AI懂你」）
2. **更大的小队与同行**：把备考营、班级、长跑队的真实进度放在一处，安静地看见彼此的进度、认真地走，不吵不卷。（具体场景：备考 / 早起 / 健身 / 学外语）
3. **年度报告与年度印记**：一年走完，留一份只属于你的真实记录，可以导出、可以回看，不喧哗。（避「养成系 / 萌宠」；「年度印记」守成就系统避免过度游戏化红线，仅作真实轨迹注脚，非游戏化奖励）

### 9.3 禁用词自检（已规避）

## 10. 风险与假设

| 风险 | 应对 |
|------|------|
| 过早变现伤留存 | 严守第 7 节启动门槛，未达标不上付费；轻度会员非付费墙 |

| 用户付费意愿低于预期 | 3%–8% 为宽区间；先用探针验证意向再开发支付；首年优惠降门槛 |
| 内容工时成本需持续投入 | 验证期会员收入非全成本回收，靠 0 预算内容引擎维持；放量后会员覆盖增量 AI 成本并逐步改善单位经济 |
| iOS / 安卓支付差异与费率 | 统一走微信虚拟支付，道具双端互通；费率以开通时公示为准，定价预留摩擦空间 |

**假设汇总**：
1. 0 预算方案 550 激活达标（北极星基线成立）。
2. 微信虚拟支付类目与费率维持当前框架（工具 / 社交类可开通，iOS 已开放）。
3. 目标用户付费力近似竞品区间（¥12–30/月）。
4. 深度复盘大模型边际成本可控，会员费能覆盖该增量。
