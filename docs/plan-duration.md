# 可变计划周期

- 新计划周期使用 `planDurationDays`，合法范围为 3～90 天。
- 旧数据继续读取 `durationDays`、`totalDays` 和 `endDate`，不要求数据库迁移。
- 3～90 天计划一次生成完整每日行动，`days` 必须覆盖完整 `planDurationDays`。
- `planOutline` 根据每个 7 天区块的真实主题和行动生成递进摘要，不得机械复制同一重点。
- 新计划不再保存 `detailedWindow`，确认时直接保存完整 `stagePlan.days`。
- 旧分窗计划进入计划页时由服务端一次性补齐缺失执行日，客户端不再提供手动展开入口。
- AI 超时按周期动态调整：7～14 天主生成 45 秒，30 天 90 秒，60 天 135 秒，90 天 180 秒；修复请求分别为 30、60、90、120 秒。
- 客户端完整计划生成等待上限为 330 秒；部署时云函数运行时上限也必须覆盖主生成与修复的总预算。
- 计划日期到达 `plannedEndDate` 后，有未完成行动则进入 `expired`；用户继续后进入 `extended`。
- 到期不会自动生成下一计划，也不会自动跳转复盘。
- 手动行动由云函数保存，使用 `generatedBy: manual`。
