# 进步局 UI 颜色系统

本文档以进度页现有视觉为基准，统一今日页、进度页、小队页、我的页及通用组件的颜色使用。

## 1. 基准色板

| Token | 色值 | 用途 |
| --- | --- | --- |
| Primary | `#145243` | 主按钮、当前状态、关键图标、深色 Hero 起点 |
| Primary Deep | `#0F4035` | 深色渐变压暗端、强调图形阴影内侧 |
| Primary Mid | `#1D604F` | Hero 渐变中段 |
| Primary End | `#2C755E` | Hero 渐变亮端 |
| Accent Green | `#55B98B` | 图表高亮、进度渐变亮端 |
| Growth Green | `#7DBB69` | 完成率进度条、积极状态进度 |
| Gold | `#F5B94E` | 成就、里程碑、温和提示点缀 |
| Gold Light | `#FFF4CF` | 金色提示卡背景 |
| Text Primary | `#173C34` | 标题、关键数字、主要正文 |
| Text Secondary | `#6F7F78` | 辅助说明、元信息 |
| Text Muted | `#A8B0AA` | 弱提示、空状态次级信息 |
| Background | `#F7F8F5` | 页面背景 |
| Surface | `#FFFFFF` | 卡片、弹层、输入框主表面 |
| Soft Surface | `#F3F8F5` | 浅绿背景、轻量按钮、标签底色 |
| Border | `#E8EFEB` | 分割线、弱边框 |

## 2. 应用规则

- 页面背景统一使用 `#F7F8F5`，不要使用偏灰或偏黄的背景作为主背景。
- 主卡片统一使用白色表面和绿色阴影：`0 8rpx 30rpx rgba(20, 82, 67, 0.08)`。
- 深色 Hero 使用 `linear-gradient(145deg, #145243 0%, #1D604F 58%, #2C755E 100%)`。
- 主按钮、当前目标、当前日期、当前 Tab 强调统一使用 `#145243`。
- 完成率、贡献热力图、趋势图的积极状态优先使用 `#7DBB69` 或 `#55B98B`，避免混入过多蓝紫红。
- 金色只用于成就、里程碑、温和提示，不作为大面积页面底色。
- 小队页成员、标签、按钮等元素不得使用过浅的绿导致识别弱；浅绿背景必须搭配 `#145243` 文本。
- 我的页 Hero 和弹层遮罩避免过重黑绿阴影；遮罩建议使用 `rgba(31, 45, 42, 0.34)`。

## 3. 禁用和慎用

- 禁止将 `#356859`、`#1F5B4A` 作为新页面主色；旧页面应逐步迁移到 `#145243`。
- 避免使用 `#0F4B3D` 作为大面积起始色，它会比进度页基准更沉。
- 避免高饱和红色作为失败或警告状态；需要提醒时优先使用柔和金色或低饱和棕红。
- 避免同一页面同时出现多套绿色深浅体系。

## 4. 页面映射

- 今日页：使用进度页同源主色，Hero、日期选中、添加行动入口保持 `#145243`。
- 进度页：作为当前色彩基准，不随意新增主色。
- 小队页：成员头像占位、标签、按钮、进度条要比旧版更清晰，统一使用 `#145243` 文本与 `#F3F8F5/#EEF7F2` 背景。
- 我的页：降低深色 Hero 和阴影重量，金色点缀统一到 `#F5B94E`。
