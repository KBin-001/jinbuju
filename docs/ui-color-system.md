# 今日进度｜目标计划打卡现代东方山水视觉系统

本系统以现代、年轻、安静的东方山水为品牌语言。山水负责建立方向感，UI 负责清晰表达真实行动数据；页面不能退化为古风海报，也不能变成没有识别度的纯色组件库。

## 基准色板

| Token | 色值 | 用途 |
| --- | --- | --- |
| Page | `#F7F3EA` | 温润米白页面底色 |
| Surface | `#FFFCF6` | 卡片、弹层和输入表面 |
| Primary | `#245B4D` | 主按钮、当前状态、关键图标 |
| Secondary | `#7F9D91` | 次级图表、进度和辅助图形 |
| Gold | `#C89B4A` | 里程碑、选中日期和克制点缀 |
| Text | `#24312D` | 标题、数字和正文 |
| Text Secondary | `#7C817D` | 说明与元信息 |
| Border | `rgba(121,111,91,.13)` | 暖灰边框与分隔线 |

成功、提醒、错误分别使用墨绿、暖金和低饱和棕红，不使用同一种绿色表达所有状态。

## 山水使用

- 今日使用晨雾山峰，进度使用登山路径，小队使用群山同行，我的使用远山薄雾。
- 每个主页面只保留一个主要山水区域；其他卡片保持干净表面。
- 图片必须使用无文字版本，配合透明遮罩和留白区承载内容。
- 文字不得落在高对比山体上；常见屏幕裁切后仍需保持可读。
- 优先使用当前小于 200KB 的 JPG，确认无引用后再移除同内容大尺寸 PNG。

## 排版与组件

- 品牌名和 Hero 标题可少量使用宋体；正文、数据、按钮、榜单和 TabBar 使用系统无衬线字体。
- 页面左右边距统一为 `32rpx`，同级卡片圆角使用 `24–32rpx`。
- 主按钮高度至少 `88rpx`，任务完成控件视觉可更小但点击区不少于 `88rpx`。
- 卡片阴影控制在 `0 8rpx 24rpx rgba(75,62,40,.05–.07)`，禁止发光与重悬浮。
- 头像使用真实图片和统一默认头像；多人概览最多四个头像，剩余人数显示 `+N`。

## 页面映射

- 今日：日期与日历、紧凑执行状态、AI 建议、行动列表。
- 进度：登山目标 Hero、周/月趋势、年度热力图和 AI 复盘。
- 小队：山水房间卡、真实纵向行动榜与高价值动态。
- 我的：远山身份 Hero、当前目标、本周摘要、成长收藏和账号设置。

不得为单独页面新增第二套色板或大面积硬编码主题覆盖。
