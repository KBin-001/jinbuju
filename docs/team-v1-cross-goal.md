# 跨目标自律小队 V1

## 定位

小队不按目标类别匹配。学习、运动、求职、创作等不同目标的用户都可以加入同一个 3～5 人自律小队。

## 成员公开信息

- 用户主动设置的小队昵称和头像
- 当前目标标题
- 今日是否完成行动
- 今日已完成行动的预计时长合计
- 连续行动天数
- 阶段完成率
- 收到的固定鼓励数

不展示 OPENID、微信号、手机号、完整目标说明或打卡备注。头像先上传云存储，数据库只保存 `cloud://` fileID。昵称和头像更新必须经过云函数身份校验。

## 匹配与限制

- 不再使用目标类别、阶段开始日期或阶段结束日期作为匹配条件。
- 每名用户只能有一个有效小队成员关系。
- 每队最多 5 人，加入操作通过事务校验人数并防止重复加入。
- V1 不提供排行榜、私聊、自定义评论或任意鼓励文案。
- 今日行动时长由云函数读取任务并计算，客户端不可提交统计值。

## 固定鼓励

V1 只允许：`今天也要加油`、`你太稳了`、`明天继续`、`一起坚持`。同一发送者每天对同一成员最多发送一次。
