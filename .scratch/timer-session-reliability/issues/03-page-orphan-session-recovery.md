# 03 — 页面：孤儿会话恢复态

**What to build:** 当服务上下文返回 `task: null`（活跃会话存在但关联任务已被软删除）时，悬浮计时条不隐藏，而是进入恢复态：显示极简信息（如「行动已删除」）与会话已耗时，只保留一个「结束并清理」操作，调用现有的 `abandonActionSession(keepTime=false)` 清除残留会话。恢复态不展示「暂停/继续」，因为没有可锚定的任务。这消除了「会话存在但任务不可见」导致的死锁——用户始终能清除残留会话、恢复正常使用。
