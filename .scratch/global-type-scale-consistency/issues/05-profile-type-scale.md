# 05 — 迁移“我的”及个人数据流程字号

**What to build:** 将“我的”首页及个人资料、目标摘要、成长记录、成就、账号和隐私设置迁移到语义字号体系，让身份、当前目标、阶段成长和设置区域层级清晰，并与其他主 Tab 保持一致的阅读密度。

**Blocked by:** 01 — 建立语义字号阶梯与兼容契约。

**Status:** resolved

- [x] 个人身份、当前目标、阶段成长、本周摘要和设置分区使用明确且一致的标题与正文层级。
- [x] 用户名称、真实头像旁的信息、目标摘要和成长数据不会因字号过大压过核心操作。
- [x] 成就与成长收藏的名称、状态、说明、日期和统计使用克制的语义字号，不产生过度游戏化的视觉重量。
- [x] 成长记录时间线中的日期、行动标题、投入信息和复盘内容与进度页记录层级一致。
- [x] 编辑资料、公开展示、账号、通知、隐私、数据导出和其他设置项使用统一的字段、说明和操作字号。
- [x] 危险操作、确认弹层、加载、空数据、错误与重试状态符合全局字号规范。
- [x] 长昵称、长目标名、长成就说明、小屏和系统字体放大场景不溢出或遮挡按钮。
- [x] 个人资料与敏感数据展示范围不因样式迁移而扩大，业务与隐私逻辑保持不变。
- [x] “我的”相关契约、视觉保真测试、类型检查和编译通过。

## Answer

“我的”首页、成长记录、成就、账号安全、数据管理、数据同步、隐私中心和法律页面已统一语义字号；敏感数据展示范围与业务逻辑未改动。个人页、子页面、成长记录和排版契约通过，详见 [map](../map.md)。
