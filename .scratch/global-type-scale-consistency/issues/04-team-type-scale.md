# 04 — 迁移小队及成员流程字号

**What to build:** 将小队首页、今日行动榜、小队动态、成员详情、邀请和设置流程迁移到统一字号体系，使排名、真实头像、任务、状态与投入时间层级清楚，并与今日和进度页面保持相同的产品阅读密度。

**Blocked by:** 01 — 建立语义字号阶梯与兼容契约。

**Status:** resolved

- [x] 小队名称、口号、房间号、成员人数和顶部统计分别映射到合适的标题、正文、元信息或数据层级。
- [x] 邀请好友、小队设置和复制房间号入口使用统一按钮或操作文字层级，并保留真实反馈。
- [x] 今日行动榜的成员名、今日任务、状态标签、投入时间、完成进度和排名使用清晰且一致的语义字号。
- [x] 榜单与上一名差距、鼓励文案和开始行动入口不过度放大，也不制造羞辱或焦虑感。
- [x] 小队动态的事件标题、说明和时间信息与榜单同角色文字保持一致。
- [x] 成员详情半屏、完整成员管理、邀请、加入和小队设置流程使用统一的标题、正文、标签和危险操作层级。
- [x] 队长与普通成员状态、危险操作确认、加载、空数据、错误和重试界面均符合字号规范。
- [x] 长小队名、长成员名、长任务名、小屏和系统字体放大场景不溢出或遮挡操作。
- [x] 小队相关契约、视觉保真测试、类型检查和编译通过。

## Answer

小队首页、行动榜、成员详情、成员管理、邀请、动态、设置和状态弹层已按标题/正文/说明/标签/数据层级统一。房间号仍保留复制入口与反馈，头像和业务权限逻辑未变。小队模块、角色权限、设置和视觉契约通过，详见 [map](../map.md)。
