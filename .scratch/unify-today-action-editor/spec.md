# 统一今日行动编辑入口

Status: ready-for-agent

## Problem Statement

用户已经在“今日”页拥有完整、可用的“添加行动”半屏编辑器，但进度页周进度 AI 教练的“安排任务”以及若干查看、编辑和新增行动入口仍会打开旧的全屏行动编辑页。两个编辑体验并存，视觉、字段和交互不一致，也让用户误以为新设计没有生效。

## Solution

把“今日”页的行动半屏作为项目唯一的行动新增与编辑体验。来自进度、AI 教练、行动记录、今日数据和目标详情等页面的入口先切换到“今日”Tab，再自动打开同一个半屏，并带入目标、日期或待编辑行动。移除旧全屏行动编辑页、路由声明、预加载配置和旧页面专属测试，不改变底层行动数据与同步契约。

## User Stories

1. As an 查看周进度的用户, I want 点击 AI 教练的“安排任务”后进入今日页的添加行动半屏, so that 我使用的是当前统一的行动体验。
2. As an 查看建议行动的用户, I want 安排建议时默认带入建议日期, so that 我不需要再次选择日期。
3. As an 从进度页添加今日行动的用户, I want 直接看到今日页添加行动半屏, so that 页面体验与今日页一致。
4. As an 从目标详情添加行动的用户, I want 新行动继续关联原目标, so that 数据不会被写入错误目标。
5. As an 从行动记录查看未完成行动的用户, I want 在今日页统一半屏中编辑它, so that 不再遇到旧页面。
6. As an 从 AI 教练查看行动的用户, I want 在今日页统一半屏中查看并调整行动, so that 编辑字段和保存反馈保持一致。
7. As an 编辑历史或未来行动的用户, I want 半屏正确带入原行动的日期和内容, so that 修改不会丢失已有设置。
8. As an 编辑行动的用户, I want 继续修改名称、预计投入、执行方式、重要程度、日期和提醒, so that 旧页面移除后业务能力不缩水。
9. As an 编辑行动的用户, I want 继续删除行动并看到二次确认, so that 危险操作仍安全可控。
10. As an 新增行动的用户, I want 保存后同步真实数据并刷新今日页, so that 今日状态、目标进度和后续统计保持一致。
11. As an 没有可用目标的用户, I want 被引导创建目标, so that 添加行动不会进入无结果状态。
12. As an 遇到已删除或失效行动的用户, I want 看到明确错误反馈, so that 页面不会打开空白编辑器。
13. As an 小程序用户, I want 所有旧行动编辑入口都不可达, so that 产品中不再出现两套编辑模板。
14. As a maintainer, I want 旧全屏页面和路由被移除, so that 后续只维护今日页一套行动编辑代码。
15. As a maintainer, I want 跨页面打开编辑器使用统一导航契约, so that 新入口不会再次硬编码旧页面路径。

## Implementation Decisions

- “今日”页半屏是新增与编辑行动的唯一界面和最高层测试缝隙。
- 新增一个轻量的跨页面导航请求契约，仅传递新增或编辑模式、目标标识、行动标识和日期；请求被今日页消费后立即清除，避免重复打开。
- 跨 Tab 导航使用微信小程序原生 Tab 切换，今日页在显示时消费请求并打开半屏。
- 编辑请求按行动标识读取真实行动；无效、已删除或不可编辑的行动显示反馈，不伪造内容。
- 新增请求保留目标与日期语义；需要时让今日页聚焦对应的有效目标，再打开半屏。
- 今日页半屏继续复用现有行动服务、提醒授权、云端同步、加载刷新和错误反馈。
- 删除旧全屏行动编辑页及其页面注册、预加载配置和所有直接路由引用。
- 不修改行动数据模型、云函数接口或统计口径。

## Testing Decisions

- 以路由契约测试验证所有跨页面新增、查看和编辑入口都调用统一导航契约，代码库中不再出现旧页面路径。
- 以今日页半屏契约测试验证新增与编辑共用同一界面，并继续具备字段、保存、删除、日期、提醒和安全区处理。
- 以导航请求单元测试验证请求校验、一次性消费和异常数据清理。
- 复用现有进度 AI 教练、今日行动编辑器、行动图标、任务分组与性能资源契约测试；断言外部行为，不依赖具体内部组件层级。
- 运行 TypeScript 类型检查和仓库现有 Node 契约测试，确认路由移除后无悬空引用。

## Out of Scope

- 不重做今日页添加行动半屏的视觉设计。
- 不新增行动字段、AI 自动生成数据或新的行动数据模型。
- 不调整目标、登录、支付、隐私和云函数契约。
- 不改变完成记录专用编辑器及实际投入记录流程。

## Further Notes

- 用户提供的截图用于确认需要保留的目标体验，即今日页现有“添加行动”半屏，而不是旧全屏行动编辑页。
- “安排任务”仍可安排到建议日期，但承载界面统一为今日页行动半屏。
