# 01 — 统一进度 AI 教练的行动安排入口

**What to build:** 用户在进度页查看周、月或年趋势后，点击 AI 教练的“安排任务”，应切换到今日页并自动展开今日页现有的行动半屏。半屏需要保留当前目标和教练建议的行动日期，保存后继续走真实行动数据、提醒和同步闭环，不再打开旧全屏编辑体验。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 进度页 AI 教练“安排任务”切换到今日 Tab，并自动展开统一行动半屏。
- [ ] 跨页面请求能够传递新增模式、目标标识和有效业务日期，并在今日页消费后立即清除。
- [ ] 今日页能够根据请求聚焦有效目标；目标不存在或已结束时给出明确反馈，不创建错误数据。
- [ ] 教练建议的日期正确带入半屏，用户仍可在现有允许范围内调整。
- [ ] 保存继续复用今日页现有新增、提醒授权、云端同步、加载和错误反馈流程。
- [ ] 重复进入今日页不会再次打开已经消费的行动编辑请求。
- [ ] 契约测试覆盖进度教练入口、一次性请求消费和今日页半屏打开行为。
