# 02 — 迁移其他行动新增与编辑入口

**What to build:** 用户从 AI 教练、行动记录、今日数据或目标详情发起新增、查看或编辑普通行动时，应统一回到今日页行动半屏，并准确带入目标、日期或原行动内容。完成记录仍使用只处理实际投入和完成时间的专用编辑体验，避免行动配置与完成记录混用。

**Blocked by:** 01 — 统一进度 AI 教练的行动安排入口

**Status:** ready-for-agent

- [ ] AI 教练中的普通行动查看与编辑入口使用今日页统一半屏。
- [ ] 行动记录中的新增和未完成行动编辑入口使用今日页统一半屏。
- [ ] 今日数据中的添加行动入口保留当前查看日期并使用今日页统一半屏。
- [ ] 目标详情中的添加行动入口保留原目标关联并使用今日页统一半屏。
- [ ] 编辑已有行动时正确带入名称、预计投入、执行方式、重要程度、日期、提醒和已有图标信息。
- [ ] 编辑历史或未来行动时不依赖今日列表是否已渲染该行动，并继续支持保存和删除。
- [ ] 行动已删除、所属目标不存在或目标已结束时显示明确反馈，不打开空白编辑器。
- [ ] 最近完成记录继续使用完成记录专用编辑器，不进入行动配置半屏。
- [ ] 契约测试覆盖所有迁移入口，并确认没有入口重新硬编码旧页面地址。
