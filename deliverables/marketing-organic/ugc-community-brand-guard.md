# jinbuju · UGC 与社群分享的品牌守护指引（0 预算自然传播版）

**产出人**：品牌分析师（品析 / Brandi）
**日期**：2026-07-20（补充于原 B2C 战役方案之后）
**适用场景**：战役从「小预算试投」改为「0 预算自然流量」——获客主引擎变为用户自发分享（UGC）、社群自然传播、公众号/视频号内容复利。
**性质**：本指引为**补充**，非替代。差异化定位、品牌声音基线、messaging 守护线（禁用词、同质化规避对照、素材自查清单 A1–A5）及首批已过审素材**全部不变、直接沿用**；本文仅覆盖此前未专门覆盖的「自然传播 / UGC / 社群」角度。

## 0. 调性锚（不变，全文以此为准）

- **品牌声音基线**：安静、克制、温润，像山间向导；鼓励不喊口号，陪伴有分寸，不制造焦虑。
- **视觉基调**：现代东方山水（温润米白 #F7F3EA / 深墨绿 #245B4D / 灰青绿 #7F9D91 / 克制金 #C89B4A），留白、安静、有品质——是「现代东方」，不是「古风养生」。
- **四力咬合（差异化）**：小队给关系、AI 给方法、真实数据给信任、东方山水给质感。
- **品类边界（反复重申）**：不是打卡清单、不是待办、不是虚拟养成。
- **产品红线（来自 AGENTS）**：鼓励功能应轻量（不演化成聊天系统）；成就系统避免过度游戏化；不使用 Emoji 代替正式功能图标；避免「坚持就是胜利」等空泛口号；小队是轻量陪跑，不是社交平台。

## 1. UGC 调性守护线

当用户自发晒「真实进度 / 小队排名 / 连续行动天数」时，内容天然容易滑向以下雷区。逐条给出冲突点与引导原则。

### 1.1 雷区清单

| 雷区 | 典型表现 | 与品牌冲突点 |
|------|----------|--------------|
| 焦虑炫耀 | 「连续 200 天我还没断，你们呢？」、晒排名鄙视落后 | 违反「不制造焦虑 / 不羞辱」；把陪伴异化为竞赛 |
| 古风养生 | 「晨间一杯温水，静坐养气，自律即修行」 | 命中禁用词「养生 / 禅意 / 古风」；偏离现代东方山水（那是古风，不是我们的东方山水） |
| 模仿竞品可爱打卡 | 堆萌宠/可爱表情、「今天也是元气满满的一天」 | 命中禁用词「萌宠 / 可爱 / 养成系」；落入竞品「马卡龙可爱」同质化 |
| 堆 Emoji | 🔥💪🌟✨ 满屏、用 🌳 表示连续打卡 | 违反 AGENTS「不使用 Emoji 代替正式功能图标」；像竞品卡通森林 |
| 口号式坚持 | 「坚持就是胜利」「自律给我自由」「逼自己一把」 | 直接命中禁用词；口号空泛 |
| 种树 / 养成叙事 | 「今天又种下一棵小树」「养成的第 N 天」 | 落入竞品 Forest / 种子习惯「虚拟成长物」；命中「种下希望 / 养成系」禁用 |
| 待办清单叙事 | 晒一长串待办、强调「清空清单的爽感」 | 违反定位「不是打卡清单 / 不是待办」；品类误读 |

### 1.2 引导原则（确保 UGC 仍落在调性内）

- **真实先于漂亮**：鼓励晒「今天做了哪一件 + 一点真实感受」，而非排名数字或连续天数战绩。真实可信 > 好看。
- **安静克制，不喊口号**：UGC 像山间向导的低声提醒，不是啦啦队。用「有人陪你把目标走完」式陈述，不用「冲啊坚持住」。
- **陪伴而非竞赛**：小队排名是「互相看得见」，不是「比谁强」。引导语强调「今天有人等你开始」，而非「你落后了」。
- **东方山水的现代感**：照片 / 配图走米白留白、墨绿 + 克制金，像日常书桌 / 晨间一角；不堆山峰祥云（那是古风，不是我们的东方山水），不堆萌宠。
- **反虚拟成长物**：晒「真实进度 / 真实数据」，明确区别于「种树 / 养成」。连续天数只是真实轨迹注脚，不是养成游戏等级。
- **不制造焦虑**：零羞辱、零「你不行就掉队」。停更 / 慢节奏也被接住（呼应 AI 教练「这周慢了但没断，稳住了」）。

> 口径说明：AGENTS.log 中 V1 预设固定鼓励含「一起坚持」，属产品内轻量微文案，与「口号式坚持」红线是两回事；**对外 UGC / 社群分享不主动扩散「坚持」口号**，保持品牌审核已确认口径（「坚持」仅留于「陪伴式长期坚持」定位概念，口号钩子位已全部场景化）。

## 2. 社群分享话术基线（考研群 / 自律社群，KOC 与用户自然分享）

### 2.1 该说（DO）—对齐已交付 DO 话术与品牌锚

- 以第一人称真实分享：「我换了种不一个人扛的方式」「拉了几个研友每天发进度」。
- 用已锁定的品牌锚点话术：
  - 「有人陪你把目标走完」
  - 「今天该做什么 3 秒看清」
  - 「小队同行，有人等你一起行动」
  - 「真实进度看得见、信得过」
- 锚定真实个人节奏：「这是我个人的情况，快慢看自己，不必和谁比」。
- 引导动作轻量：微信里搜 jinbuju / 找个搭子一起打卡（统一 CTA，不堆链接）。
- 话题标签用已批准库（每条 3–5，含 1 场景 + 1 差异）：`#习惯打卡 #考研打卡 #学习搭子 #早起打卡 #目标管理 #AI教练 #小队同行 #连续行动打卡`。

### 2.2 不该说（DON'T）—对齐禁用词 + 同质化规避

- **禁用词全清单（沿用，零容忍）**：坚持就是胜利 / 自律给我自由 / 自律改变人生 / 告别拖延症 / 逼自己一把 / 21 天养成好习惯 / 轻松逆袭 / 月入 / 暴富 / 种下希望 / 种下梦想 / 养成系 / 萌宠 / 可爱 / 古风 / 养生 / 禅意 / 海报化 / 全能 / 第一 / 最好 / AI 替你规划人生 / AI 懂你。
- **自然语境最易脱口而出的三句（重点盯防）**：
  - ❌「坚持就是胜利」 → 改用「有人陪你把目标走完」「慢慢走，别停」。
  - ❌「自律给我自由」 → 改用「找几个同行的人，比一个人硬扛轻松」。
  - ❌「种下希望 / 种下梦想」 → 改用「今天这一小步走完就好」。
- **同质化竞品话术（沿用）**：不说「种树 / 种出森林 / 养成好习惯告别拖延 / 社区打卡互相监督」；不模仿「可爱打卡 / 元气满满」。
- **不承诺未经证实结果**（A3 DON'T：未经证实数据）：不说「用这个 100 天必上岸」「跟我 21 天逆袭」。
- **不把进度当战绩施压**：不说「连续 N 天了你还不来？」「看看你的排名」。

### 2.3 KOC / 用户分享结构（仅给结构，不给成稿文案）

- **结构** = 个人真实痛点 + 换了什么方式 + 一个真实小瞬间 + 轻引导。
- **语气** = 像在群里跟朋友聊，不像发广告。
- **红线** = 不硬广、不堆链接、不用感叹号轰炸；自然口语里最容易无意识溜出「养生一下 / 古风感 / 元气满满」，需自检。

## 3. 鼓励机制调性（0 预算裂变杠杆：邀请进小队 / 晒进度）

0 预算下，老用户邀请进小队、晒进度是核心裂变杠杆。机制要**轻量、不贩卖焦虑、不过度游戏化**。

### 3.1 调性建议

- **轻量优先**（呼应 AGENTS「鼓励功能应轻量，避免演变成复杂聊天系统」）：鼓励是「轻拍一下肩膀」，不是弹窗轰炸、不是连续任务链。固定鼓励用预设温和句（产品侧 V1 已限定预设，不允许自由输入）。
- **不贩卖焦虑**：不用「再不行动就掉队 / 错过今天全白费」式倒计时恐吓；停更也被接住，回归无压力。
- **不过度游戏化**（呼应 AGENTS「成就系统避免过度游戏化，视觉上保持克制」）：连续天数、小队排名是真实轨迹注脚，不做等级 / 勋章 / 排行榜羞辱；小队动态只展示高价值事件（完成行动、连续达成、阶段里程碑）。
- **真实数据给信任**：鼓励基于真实进度（「你这周慢了但没断，稳住了」），不是空话「你真棒」。
- **邀请机制调性**：鼓励「叫上同行的人」，不是「拉人头得奖励」。轻量邀请话术如「想一起走的朋友，我拉你进小队」；不做拉人排行榜 / 物质佣金（与 0 预算调性 & V1 禁止项一致）。
- **晒进度引导**：产品内给「分享今日这一步」的轻入口（真实截图 / 真实数据，非虚拟成长物），不诱导「晒连续天数战绩」。

### 3.2 文案 / 机制调性红线

- 鼓励语做**事实陈述**（看真实数据），不做口号。
- 不出现「坚持就是胜利」式口号、不出现「自律给我自由」。
- 进度分享默认带「个人节奏」语境，不暗示普遍结果。

## 4. 自然内容防误读清单（补充进已有 A5 素材自查清单）

0 预算长期做内容，单篇易因追流量滑向「待办清单 / 种树养成 / 古风养生」同类叙事。在已有 A5 基础上，自然流量 / UGC / 社群场景**额外自查**：

- **A5-N1 品类边界自检**：每篇开头是否明确「不是打卡清单 / 不是待办 / 不是虚拟养成」？追流量时最容易在标题偷换回「清单 / 养成」钩子。
- **A5-N2 视觉调性自检**：配图 / 截图是否仍是现代东方山水（米白留白 + 墨绿 + 克制金），而非古风养生（祥云 / 书法 / 茶道）、非竞品可爱（萌宠 / 马卡龙）、非卡通森林（满屏树 / 🌳）？
- **A5-N3 用词同质化自检**：是否蹭了竞品高频词（种树 / 养成 / 元气满满 / 互相监督 / 社区打卡）？是否误用禁用词（养生 / 禅意 / 古风 / 可爱 / 养成系）？自然口语里「养生一下」「古风感」最容易无意识溜出。
- **A5-N4 数据真实自检**：引用的连续天数 / 进度是否真实、是否标注「个人情况」语境？不把用户个案当品牌承诺（A3 DON'T）。追流量时易把「100 天」当卖点放大 → 禁止。
- **A5-N5 焦虑 / 竞赛自检**：是否制造「不行动就落后 / 羞辱式排名」？小队 / 进度内容是否回到「有人陪你走」而非「比谁强」？
- **A5-N6（可并入口语分享）Emoji / 口号自检**：是否用 Emoji 代替功能图标或堆表情？自然口语分享是否溜出口号式「坚持 / 自律给我自由」？

> 建议 team-lead 将 A5-N1 ~ N6 并入现有 A5 素材自查清单的「自然流量 / 社群 / UGC」子项，与原 A1–A5 一并作为发布前必查。

## 5. 一句话收口（0 预算自然传播下品牌守护核心原则）

> **自然传播不靠喊口号拉人，靠真实的人把真实的脚步，安静地走给同行的人看。**

动作化表述（供主理人选择）：让用户用**真实的进度、安静的语气、现代东方的质感**，替我们把「有人陪你把目标走完」说给下一个人听——**不焦虑、不炫耀、不模仿竞品**。
