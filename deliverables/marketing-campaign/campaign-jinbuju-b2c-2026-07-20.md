## 1. 战役策略（来自策略）

### 1.1 目标
- **北极星**：激活用户数（新注册且完成「今日」Tab 首次行动提交）≥450（区间 400–700）。
- **过程漏斗**：曝光≥25万 → 点击/扫码≥4,000（CTR≥1.8%）→ 注册≥1,000（扫码→注册≥22%）→ 激活≥450（激活率≥45%）→ D1≥30% / D7≥15% → 小队创建/加入率≥35%。

### 1.2 受众画像
- **Persona A 考研孤勇者（21–23 岁备考党）**：一个人学易摆烂，要可见进度+AI 复盘；出没朋友圈 / 学习公众号 / 方法视频号 / 考研社群。
- **Persona B 习惯养成困难户（22–25 岁职场新人）**：试过很多 App 都卸载，要轻量不折腾+有人一起；出没朋友圈 / 视频号 / 搜一搜 / 自律社群。

### 1.3 核心 message
- **主主张（品牌锚点）**：**不是打卡清单，是陪你把长期目标走完的同行小队。**
- **三支撑点**：① 小队同行（最易感知、最难复制）② 真实进度可信（反虚拟养成）③ AI 教练用真实数据复盘（赛道 0 竞品，次屏展开）。
- **Persona 变体**：考研党「备考最难的不是开始，是一个人撑不到考前」；职场新人「试过 5 个习惯 App 都卸载了？每天 3 秒告诉你今天做哪件，小队陪你别掉队」。

### 1.4 渠道组合与理由
- 朋友圈广告：转化主阵地，扫码直跳，路径最短。
- 微信广告流量位：阅读/使用场景拦截，扩量获客。
- 视频号：种草 + 建立品质感，避免被读成古风养生。
- 搜一搜：捕获主动需求，低成本、意向高。
- 社群/公众号合作：精准转化 + 冷启动，为小队提供首批同伴。

### 2.1 竞品扫描结论
最相关竞品：**小日常**（极简 solo 打卡，零社交零 AI）、**种子习惯**（社区+虚拟花园，无 AI）、**Forest**（专注种树游戏化，无 AI）。滴答清单/番茄ToDo 属待办 GTD 品类，需主动划清边界。

### 2.3 蓝海洞察（三块空白）
1. 赛道 0 家做 AI → 我们是 AI-native。
2. 三家都用「虚拟成长物」（卡/花园/树）→ 我们用真实数据进度。
3. 视觉清一色可爱治愈 → 我们的现代东方山水高级克制是独家空位。
→ 四力咬合：**小队给关系、AI 给方法、真实数据给信任、东方山水给质感**。

## ⚠️ 风险 & 假设
- 假设微信定向能较准触达 20 岁上下人群；扫码直跳链路顺畅无阻断。
- **风险1 起量慢样本薄**：小预算易样本不足 → 预算集中 1–2 主渠道，必要时延至 5 周。
- **风险2 扫码即走激活低**：第 0 周必须做好首启引导与今日默认模板。
- **风险3 留存天然偏低**：第 3 周上线连续行动奖励 + AI 每日提示 + 小队绑定。
- **风险4 小队冷启动难**：系统推荐小队/默认房间兜底 + 邀请激励。
- **风险5 品类误读**：用户易把我们当待办清单/种树养成 → 所有素材首句划清「不是打卡清单/不是待办/不是虚拟养成」。
- **风险6 归因困难**：社群/视频号种草难归因 → 渠道参数 + 来源问卷。
- **假设7** 微信搜索量无公开精确数据，关键词热度为方向性估算，上线后用微信指数校准。
- **注意项（来自品析）**：①「进步局」中文名未经官方确认，全稿暂以 jinbuju 为主，发布前需市场负责人确认命名；②「连续打卡 100 天」属用户自述，须确认真实并加「我个人的情况」语境，勿以品牌口吻承诺普遍结果。
