## 1. 战役策略（来自策略）

### 1.1 北极星与过程指标
- **北极星**：激活用户数（新注册且完成首次行动，如创建/加入小队或记录第一条真实进度），12 周累计 **目标 550，区间 400–800**。
- **过程指标**（周度驱动迭代、月末校准方向）：

| 指标 | 目标 | 区间 |
|------|------|------|
| 累计自然曝光 | 100,000 | 80k–150k |
| 累计注册数 | 1,000 | 800–1,500 |
| 激活率（注册→激活） | 45% | 40%–55% |
| D1 留存 | 35% | 30%–40% |
| D7 留存 | 18% | 15%–22% |
| 小队率（激活用户中进小队占比） | 50% | 45%–60% |
| UGC 产出数 | 120 | 80–200 |
| 裂变邀请数 | 400 | 250–600 |
| 搜索占位词数（前 3 页） | ≥15 | ≥10 |

### 1.2 核心 message（沿用锚点，不变）
- **主锚点**：「不是打卡清单，是陪你把长期目标走完的同行小队」。
- **三个支撑点（差异化优先级）**：①小队同行（最易感知、最难复制）②真实进度可信（反虚拟成长物）③AI 教练用真实数据复盘（赛道独家，次屏展开）。
- **受众变量**：对 A「一个人备考太容易停？jinbuju 小队陪你，进度是真实的学习」；对 B「试过的自律 App 都卸载了？jinbuju 轻量不折腾，小队陪你别掉队」。

### 1.3 渠道组合（全自然，5 杠杆）
1. **公众号内容矩阵**：种草 + SEO 长尾承接 + 信任建立；连载形成追读与订阅沉淀，是内容复利主载体。
2. **视频号自然分发（不加热）**：靠选题质量 + 话题标签 + 社交转发获自然流量；竖屏真实感比精致广告更易转发。
3. **搜索占位引擎（搜一搜免费 + 小程序搜索配置）**：高意向获客 + 转化，流量即需求，是 0 预算转化效率最高杠杆。
4. **小红书 / 朋友圈 / 社群 UGC**：种草 + 口碑裂变；用户晒真实进度天然适配「种草/见证」语境，降低分享门槛使每次完成成免费获客触点。
5. **老用户裂变（邀请进小队 + 真实进度可晒）**：产品设计上「小队同行」本身需拉人，「真实进度可晒」自带见证属性；用非现金激励（徽章/AI 复盘解锁）替代付费红包，社交关系链变获客渠道、反哺留存。

### 1.4 时间线（12 周四阶段）

### 2.2 0 预算新增：UGC 与社群品牌守护（品析补充，已落盘 `deliverables/marketing-organic/ugc-community-brand-guard.md`）
自然传播场景下，用户自发晒进度易滑向 6 类雷区，已建「自然内容防误读清单 A5-N1~N6」：
- **N1 品类边界**：每篇开头明示「不是打卡清单/不是待办/不是虚拟养成」。
- **N2 视觉调性**：仍现代东方山水四色 + 留白，不古风养生/不竞品可爱/不卡通森林。
- **N3 用词同质化**：不蹭「种树/养成/元气满满」，不误用禁用词。
- **N4 数据真实**：引用天数/进度标「个人节奏，快慢看自己」，不把个案当品牌承诺。
- **N5 焦虑/竞赛**：不制造「不行动就落后/羞辱式排名」，回到「有人陪你走」。
- **N6 Emoji/口号**：不堆 Emoji、不溜口号式「坚持/自律给我自由」。

**调性收口**：自然传播不靠喊口号拉人，靠真实的人把真实的脚步，安静地走给同行的人看。

## 3. SEO 关键词策略（来自优搜）

### 3.1 为什么 SEO 是 0 预算唯一可规模化的杠杆
小程序搜索配置（一次性免费占位） × 公众号/视频号内容矩阵（持续免费） × 真实使用量（排名燃料） = 可规模化自然流量。意图匹配 = 最高转化效率；内容复利 = 边际成本趋零；微信闭环 = 搜→点→用无跳转损耗。

### 3.2 小程序搜索配置（一次性免费，优先级最高）
- **名称**：维持 `jinbuju` 简短，不堆词；上线后不轻易改名（改名=权重归零）。
- **10 个自定义关键词（一次性提交审核）**：打卡小程序、学习搭子、备考打卡、早起打卡、长期目标、目标管理、小队打卡、AI教练、陪伴自律、连续行动。
- **功能介绍埋词句**（前 30 字）：「jinbuju｜小队一起打卡的长期目标管理小程序：AI 教练陪你复盘，告别一个人容易停」。
- **服务类目**：主类目 `工具 > 效率办公`；备考内容高时叠加 `教育 > 学习工具`。
- **排名启示**：用户使用量权重约 50%，真实使用是最硬排名资产 —— 内容引流后必须靠产品体验留人、用起、回来。

## ⚠️ 风险 & 假设

- **假设 A1**：内容质量稳定即可获得可预测自然分发（公众号推荐 + 视频号社交转发）。
- **假设 A2**：目标人群存在稳定搜索需求词（考研进度记录/习惯养成等），可被占位。
- **假设 A3**：真实进度可晒的产品特性足以驱动用户自发 UGC 与裂变。
